# Usage

The floating panel is draggable and minimizable. Use **Start** to begin a marked scenario, **Pause/Resume** to control collection, **Stop** to close the scenario, and **Clear** to remove only observer memory. Tabs expose request, stream, file, storage, frontend resource, scenario, and export metadata.

For one clean comparison, use one normal action per scenario. Mark start/end around the action. Review exports locally before adding them to `deepseek_web_research/captures/`.
